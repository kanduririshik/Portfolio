# Rishik Kanduri — Developer Portfolio

Live Website: **[https://kanduririshik-portfolio.vercel.app/](https://kanduririshik-portfolio.vercel.app/)**

## Overview
A modern, responsive personal portfolio built with React 18, Vite, Tailwind CSS, and Framer Motion. Showcases technical projects, full-stack and AI competencies, industry certifications, hackathons, and direct contact options.

## Tech Stack
- **Frontend:** React 18, Vite
- **Styling:** Tailwind CSS, Glassmorphism design system
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Deployment:** Vercel (CI/CD connected to GitHub `main` branch)

## Live Deployments
- **Production (Vercel):** [https://kanduririshik-portfolio.vercel.app/](https://kanduririshik-portfolio.vercel.app/)
- **Repository:** [https://github.com/kanduririshik/Portfolio](https://github.com/kanduririshik/Portfolio)

## Local Development

# Install dependencies

# Start local dev server
npm run dev
